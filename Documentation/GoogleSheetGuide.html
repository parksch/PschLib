Google Sheet Generator

Google Spreadsheet의 데이터를 C# partial class와 ScriptableObject로 변환하는 Unity Editor 도구입니다.

프로젝트 분리

Spreadsheet별 폴더와 namespace를 자동으로 분리합니다.

자동 코드 생성

시트의 이름, 자료형, 값을 읽어 C# 데이터를 생성합니다.

빠른 ID 조회

생성된 SO 데이터를 Dictionary 기반으로 조회합니다.

빠른 시작

  1. Google Sheet Server를 선택하고 Load Projects를 누릅니다.
  2. 프로젝트를 선택하고 Use Selected Project를 누릅니다.
  3. 가져올 시트를 선택합니다.
  4. Generate Selected를 눌러 C#과 SO를 생성합니다.

프로젝트 등록

Register New Project... 버튼을 누르고 이름과 Google Sheet 주소를 입력합니다.

입력 설명 예시
Project Name C# 이름으로 사용할 프로젝트 Key GameData, Test2
Sheet URL or ID 브라우저 주소 또는 Spreadsheet ID https://docs.google.com/spreadsheets/d/...
Project Name에는 영문, 숫자, 밑줄을 사용할 수 있습니다. 숫자로 시작하거나 C# 예약어를 사용할 수 없습니다.

바로가기 버튼

  • Open Registry: 등록된 프로젝트 목록 Spreadsheet를 엽니다.
  • Open Sheet: 현재 선택한 데이터 Spreadsheet를 엽니다.

시트 작성 규칙

첫 번째 행은 필드 이름, 두 번째 행은 자료형, 세 번째 행부터 실제 데이터입니다.

id name rank elements price &memo
string string senum List<senum<Element>> int string
wood_sword Wood Sword Common Physical 100 설명용 열
fire_sword Fire Sword Rare Fire,Physical 500 생성에서 제외
이름이 &로 시작하는 시트와 열은 설명용으로 취급하여 생성에서 제외합니다.

공유 enum에 새로운 값이 추가되면 기존 숫자는 유지되고 새 값은 마지막에 추가됩니다.

Generate

  1. 필요한 시트를 체크합니다.
  2. Generate Selected를 누릅니다.
  3. Unity 컴파일이 끝날 때까지 기다립니다.
  4. 생성된 Table SO와 데이터를 확인합니다.

자동 생성 파일은 수정하지 않습니다. 사용자 함수는 *.Functions.cs partial 파일에 작성합니다.

런타임 데이터 조회

Table SO는 Unity 직렬화를 위한 List와 빠른 조회를 위한 Dictionary를 함께 사용합니다.

// ID가 반드시 존재해야 하는 경우
var item = itemTable.Get("fire_sword");

// ID가 없을 수도 있는 경우
if (itemTable.TryGet("fire_sword", out var value))
{
    Debug.Log(value.name);
}

// 전체 Dictionary 확인
var allItems = itemTable.ById;
Dictionary는 SO에 중복 저장되지 않으며 데이터가 로드된 뒤 필요할 때 생성됩니다.

자주 발생하는 오류

Project name is not a valid C# identifier.
공백, 하이픈, 숫자로 시작하는 이름 또는 C# 예약어를 확인합니다.
Spreadsheet ID is already registered.
같은 Google Spreadsheet가 Registry에 이미 등록되어 있습니다.
Field type is invalid.
두 번째 행의 자료형 철자와 enum 문법을 확인합니다.
ID is duplicated.
같은 시트의 id 열에서 중복된 값을 확인합니다.
